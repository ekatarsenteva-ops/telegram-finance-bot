# Telegram-бот учёта доходов/расходов

Бот для учёта финансов двух объектов (языковая школа и недвижимость): свободные приходы,
плановые платежи, групповые расходы с отслеживанием возврата долгов, взаимозачёты.
Ввод — свободный текст на русском, разбирается через Claude API.

Реализовано ядро (Phases 1–6, 8): инфраструктура, парсинг текста, диалог уточнения,
бизнес-логика зачётов/долгов, хранение с аудитом (`raw_ai_log`), отчётность
(`/balance /debts /export`), команды `/start /help /settings`.

Вне объёма (заглушки-точки расширения оставлены): голосовой ввод (STT),
синхронизация Google Sheets (`services/sheets_sync.py` — no-op), автотесты
(вместо них — ручной чек-лист ниже).

## Phase 0 — настройка с нуля (подробно, для новичка)

Инструкция рассчитана на человека, который впервые всё это делает. Ничего не
пропускайте, выполняйте шаги строго по порядку. На каждом шаге написано, что
именно нажимать и что вы должны увидеть в результате.

Понадобится: компьютер с доступом в интернет, установленный [VS Code](https://code.visualstudio.com/)
(или любой текстовый редактор + терминал), Telegram на телефоне или компьютере.

### 1. Создать Telegram-бота

1. Откройте Telegram (на телефоне или компьютере).
2. В строке поиска введите `@BotFather` и откройте этого бота — это официальный
   бот Telegram для создания других ботов.
3. Нажмите кнопку **Start** (или отправьте `/start`).
4. Отправьте команду `/newbot`.
5. BotFather спросит имя бота (то, что будет отображаться, например `Финансы Школа+Недвижимость`) — введите любое, отправьте сообщением.
6. Затем спросит username — техническое имя, обязательно заканчивается на `bot`
   (например `myfinance_helper_bot`). Если имя занято, попробуйте другое.
7. После этого BotFather пришлёт сообщение с токеном — длинной строкой вида
   `123456789:AAExampleTokenXXXXXXXXXXXXXXXXXXXXX`.
8. Скопируйте этот токен (нажмите и удерживайте на телефоне, или выделите и
   `Ctrl+C` на компьютере) — это `TELEGRAM_BOT_TOKEN`, сохраните его пока в
   любом текстовом файле или заметке, он понадобится на шаге 5.

**Важно:** не пересылайте этот токен никому и не публикуйте его — с ним можно
полностью управлять вашим ботом. Если случайно засветили его — в BotFather
есть команда `/revoke`, которая создаёт новый токен взамен старого.

### 2. Получить ключ Anthropic API (для распознавания текста через ИИ)

1. Откройте в браузере [console.anthropic.com](https://console.anthropic.com).
2. Зарегистрируйтесь (email + подтверждение) или войдите, если аккаунт уже есть.
3. При первом входе может появиться вопрос про тип аккаунта — выбирайте
   **Individual** (личный), если это не аккаунт компании.
4. Привяжите способ оплаты (банковскую карту) — без этого API-ключи не
   работают, но платите вы только за реально использованные запросы (это не
   подписка). У новых аккаунтов иногда есть стартовые бесплатные кредиты.
5. В левом меню найдите раздел **API Keys**.
6. Нажмите **Create Key**, дайте ключу любое имя (например `finance-bot`),
   нажмите **Create**.
7. Появится ключ вида `sk-ant-api03-...` — **скопируйте его сразу**, повторно
   посмотреть его будет нельзя (только создать новый). Сохраните туда же, где
   токен бота — это `ANTHROPIC_API_KEY`.

### 3. Узнать свой telegram_id

Это просто числовой идентификатор вашего личного аккаунта в Telegram (не
имеет отношения к нашему боту).

1. В Telegram, в строке поиска (та же, где вы искали `@BotFather`), введите
   `@userinfobot` и откройте этого бота — это отдельный, посторонний бот,
   никак не связанный с ботом, который мы создаём.
2. Нажмите **Start**.
3. Бот пришлёт сообщение с вашими данными, включая строку `Id: 123456789` —
   это и есть ваш `OWNER_TELEGRAM_ID`, сохраните число.

### 4. Поднять базу данных PostgreSQL (через облачный сервис Neon, бесплатно)

Здесь не нужно ничего устанавливать на компьютер — база будет жить в облаке.

1. Откройте [neon.tech](https://neon.tech).
2. Нажмите **Sign Up**, войдите через Google (проще всего) или создайте
   аккаунт по email.
3. После входа нажмите **Create a project** (или это произойдёт автоматически
   при первом входе).
4. Название проекта — любое (например `finance-bot`), регион — ближайший к
   вам, остальное не трогайте. Нажмите **Create project**.
5. Подождите несколько секунд, пока Neon создаст базу.
6. На странице проекта нажмите кнопку **Connect** (обычно в левом верхнем углу
   или на дашборде).
7. Появится строка, начинающаяся с `postgresql://` — это готовая ссылка для
   подключения к базе, включает адрес, имя пользователя и пароль. Если пароль
   скрыт звёздочками — найдите значок "показать" (глаз) рядом, чтобы он
   отобразился в строке.
8. Скопируйте эту строку целиком (обычно есть иконка копирования рядом) — это
   и есть `DATABASE_URL`.

> **Альтернатива для тех, кто хочет базу локально:** в проекте есть файл
> `docker-compose.yml`, поднимающий Postgres через Docker (`docker-compose up -d`).
> Подходит, если на компьютере уже установлен Docker Desktop. Тогда
> `DATABASE_URL` остаётся `postgresql://finance_bot:finance_bot@localhost:5432/finance_bot`
> (менять не нужно). Если Docker не установлен — используйте Neon, как описано
> выше, это проще для новичка.

### 5. Установить Python и скачать проект

1. Убедитесь, что на компьютере установлен Python версии 3.11 или новее —
   скачать можно на [python.org/downloads](https://www.python.org/downloads/).
   При установке на Windows обязательно поставьте галочку **Add Python to PATH**.
2. Скопируйте папку проекта `telegram-finance-bot` на новый компьютер (через
   флешку, облако, или `git clone`, если проект лежит в репозитории).
3. Откройте эту папку в VS Code: **File → Open Folder**.
4. Откройте встроенный терминал: **Terminal → New Terminal**.

### 6. Настроить .env

1. В терминале, находясь в папке `telegram-finance-bot`, выполните команду
   (это создаст копию файла-примера под настоящим именем):
   ```bash
   cp .env.example .env
   ```
   На Windows (PowerShell) команда другая:
   ```powershell
   copy .env.example .env
   ```
2. Откройте появившийся файл `.env` в VS Code (он появится в списке файлов
   слева).
3. Заполните все четыре строки значениями, которые вы собрали на шагах 1–4:
   ```
   TELEGRAM_BOT_TOKEN=<токен из шага 1>
   ANTHROPIC_API_KEY=<ключ из шага 2>
   DATABASE_URL=<строка подключения из шага 4>
   OWNER_TELEGRAM_ID=<число из шага 3>
   ```
4. Сохраните файл (`Ctrl+S`).

Файл `.env` содержит секретные данные — он уже добавлен в `.gitignore` и не
попадёт в git, если вы используете систему контроля версий.

### 7. Установить зависимости Python

В терминале, в папке `telegram-finance-bot`, выполните по очереди:

```bash
python -m venv venv
```
Это создаёт изолированное окружение для библиотек проекта, чтобы они не
смешивались с остальными программами на компьютере.

Затем активируйте его:
- **Windows (PowerShell):** `venv\Scripts\activate`
- **Mac/Linux:** `source venv/bin/activate`

После активации в начале строки терминала появится `(venv)` — это признак, что
всё правильно. Теперь установите библиотеки:

```bash
pip install -r requirements.txt
```

Подождите, пока всё скачается и установится (обычно 1–2 минуты).

> **Если увидели ошибку "externally-managed-environment" (обычно на Linux):**
> значит `venv` создать не удалось. Установите недостающий пакет:
> `sudo apt install python3-venv`, затем повторите шаг заново с самого начала
> (`python -m venv venv`).

### 8. Применить миграции (создать таблицы в базе)

Не выходя из терминала (окружение `(venv)` должно быть активно):

```bash
python scripts/init_db.py
```

Вы должны увидеть:
```
Применяю: 001_init_schema.sql
Применяю: 002_seed_categories.sql
Миграции применены.
```

Это создаст 7 таблиц и засеет 2 организации ("Школа языков", "Недвижимость")
с базовыми категориями.

### 9. Запустить бота

```bash
python main.py
```

Бот стартует в режиме long polling — публичный HTTPS-эндпоинт не требуется.
В терминале должна появиться строка `Start polling` без ошибок ниже неё.
Не закрывайте терминал — пока он открыт, бот работает; закрытие остановит бота.

> **Если видите `TelegramNetworkError: Request timeout error`:** скорее всего,
> компьютер выходит в интернет через корпоративный/сетевой прокси. Задайте
> переменные окружения `HTTPS_PROXY` (и `HTTP_PROXY`) с адресом прокси перед
> запуском — бот подхватит их автоматически (см. `main.py`). Может
> дополнительно понадобиться `pip install aiohttp_socks`.

### 10. Проверить в Telegram

Откройте своего бота в Telegram (по username, который вы задали в шаге 1),
отправьте `/start`. Должно прийти приветствие со списком команд.

### 11. После первого успешного запуска — смените ключи, если делились ими в переписке

Если вы отправляли токен бота или ключ Anthropic кому-то в чате (например,
мне, в рамках этой настройки) — из соображений безопасности лучше выпустить
новые:
- Токен бота: в BotFather отправьте `/revoke`, затем `/token`, обновите
  `TELEGRAM_BOT_TOKEN` в `.env`.
- Ключ Anthropic: в console.anthropic.com удалите старый ключ и создайте
  новый, обновите `ANTHROPIC_API_KEY` в `.env`.
- После смены — перезапустите бота (`Ctrl+C` в терминале, затем `python main.py`
  заново).

## Структура проекта

```
telegram-finance-bot/
├── main.py                     # запуск aiogram polling
├── config.py                   # pydantic-settings, читает .env
├── docker-compose.yml          # postgres (опционально, если не используете Neon)
├── requirements.txt
├── .env.example
├── migrations/                 # 001_init_schema.sql, 002_seed_categories.sql
├── scripts/init_db.py          # применяет миграции по порядку
├── bot/
│   ├── routers/commands.py     # /start /help /cancel /settings
│   ├── routers/dialog.py       # свободный текст → уточнение → карточка
│   ├── routers/callbacks.py    # инлайн-кнопки
│   ├── routers/reporting.py    # /balance /debts /export
│   └── states.py               # aiogram FSM states
├── services/
│   ├── claude_parser.py        # client.messages.parse(), ParsedTransaction
│   ├── offset_manager.py       # взаимозачёты
│   ├── expense_splits.py       # групповые расходы, возврат долгов
│   ├── reporting.py            # генерация отчётов и .xlsx
│   └── sheets_sync.py          # заглушка (не реализовано)
├── db/
│   ├── connection.py           # async pool
│   └── queries.py              # все SQL-запросы
├── models/schemas.py           # Pydantic: ParsedTransaction, SplitParticipant
└── prompts/parse_system_prompt.py
```

## Ручной чек-лист (замена автотестов)

Проверяйте через реального бота в Telegram после каждого значимого изменения.

**US-1: свободный приход**
- [ ] "Пришло 15000 от Пети" → бот спрашивает объект → карточка "Приход 15000₽..." → подтверждение → "✅ Операция записана!"

**US-2: входящий платёж с зачётом**
- [ ] Сначала создать расход с зачётом: "Купили материал за 6000, зачет в аренду Ивану" (объект/категория уточнить при запросе)
- [ ] Затем: "Иван внес аренду за август, 50 тыс" → бот предлагает "Применить зачёт на 6000₽?" → Да → сумма платежа уменьшена, зачёт помечен applied

**US-3: групповой расход + возврат**
- [ ] "Пикник 9000, делим поровну на Иву, Марию, Петра" → карточка с долгами по 3000 каждому → подтверждение
- [ ] "Петр вернул свою долю" → долг Петра помечен как вернувший, пропадает из `/debts`

**US-4: балансы и долги**
- [ ] `/balance` — показывает открытые взаимозачёты по контрагентам
- [ ] `/debts` — показывает актуальный список должников (без тех, кто уже вернул)

**US-5: экспорт**
- [ ] `/export 2025-08-01:2025-08-31` → присылает `.xlsx` с колонками Дата/Объект/Тип/Сумма/Валюта/Категория/Контрагент/Статус/Кто внес
- [ ] Если были групповые расходы в периоде → второй лист "Участники расходов" с деталями

**US-6: категории**
- [ ] При уточнении категории бот предлагает кнопки из справочника, привязанного к объекту

**Дополнительно**
- [ ] `/cancel` посреди диалога уточнения — прерывает диалог, следующее сообщение начинает новый разбор
- [ ] Некорректный формат даты в `/export` (например, без двоеточия) — бот показывает подсказку по формату, не падает
- [ ] Проверить в БД, что `raw_ai_log` заполнен для каждой транзакции (см. раздел ниже "Как посмотреть данные в базе")

## Как посмотреть данные в базе (Neon)

1. Откройте свой проект на [console.neon.tech](https://console.neon.tech).
2. В левом меню выберите **SQL Editor**.
3. Введите запрос, например:
   ```sql
   SELECT raw_ai_log FROM transactions ORDER BY id DESC LIMIT 1;
   ```
4. Нажмите **Run** — результат появится под запросом.

(Если база локальная через Docker — то же самое через
`docker exec -it finance_bot_postgres psql -U finance_bot -d finance_bot`.)

## Идемпотентность миграций

Скрипт `scripts/init_db.py` отслеживает применённые миграции в таблице
`schema_migrations` и пропускает уже применённые файлы — на свежей базе
применит всё с нуля, повторный запуск на существующей базе ничего не
продублирует. Достаточно в любой момент повторно выполнить:

```bash
python scripts/init_db.py
```
