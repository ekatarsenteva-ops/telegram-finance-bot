# Саммари проекта: Telegram-бот учёта финансов

## Что это

Telegram-бот для учёта доходов/расходов двух объектов — «Школа языков» и
«Недвижимость». Пользователь пишет операцию свободным текстом
(«Пришло 15000 от Пети», «Купили материал за 6000, зачет в аренду Ивану»),
бот распознаёт её через Google Gemini, уточняет недостающие поля через диалог
с кнопками, и сохраняет в базу данных Postgres (Neon).

Ключевые возможности:
- Свободный текстовый ввод операций (доход / расход / плановый платёж)
- Диалог-уточнение недостающих полей (объект, контрагент, категория, сумма, дата)
- Групповые расходы с разделением долга между несколькими людьми
  ("Пикник 9000, делим поровну на Иру, Марию, Петра")
- Погашение долгов свободной фразой ("Ира вернула долг") — с нечётким
  сопоставлением имён (уменьшительные формы/опечатки через Gemini)
- Взаимозачёты (offset) — расход "в счёт" будущего платежа
- Команды: `/balance`, `/debts`, `/export` (Excel-отчёт), `/settings`, `/cancel`
- Ограничение доступа — бот отвечает только владельцу + списку доверенных
  Telegram ID

## Технологии

- **aiogram 3.15** — Telegram Bot framework (FSM-диалоги)
- **Google Gemini** (`gemini-flash-latest`) — распознавание естественного
  языка, структурированный вывод в JSON
- **PostgreSQL** на **Neon** (serverless) — хранение данных
- **psycopg** (async pool) — доступ к БД
- **openpyxl** (предположительно, через `services/reporting.py`) — экспорт в
  Excel

## Найденные и исправленные баги в этой сессии

1. **Контрагент проглатывал весь свободный текст.** При уточнении поля
   "контрагент" бот принимал любой ответ буквально, включая целые
   предложения. Исправлено: добавлена кнопка "Без контрагента" + валидация
   (отклоняет фразы длиннее 4 слов или содержащие цифры, просит переформулировать).

2. **Погашение долга не работало при опечатках/маленькой букве/другой форме
   имени** ("петя" вместо "Петя вернул", "Петя" вместо "Петр"). Исправлено:
   сначала ищем точное совпадение с именами из открытых долгов в базе
   (регистронезависимо), если не находим — просим Gemini сопоставить
   уменьшительную форму/опечатку с реальным именем должника.

3. **У бота не было вообще никакой проверки доступа** — любой человек в
   Telegram мог найти бота и писать операции, которые попадали в базу.
   Исправлено: `AccessControlMiddleware` — тихо отбрасывает все сообщения
   от пользователей вне списка `owner_telegram_id` + `allowed_telegram_ids`.
